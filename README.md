# AWS Developer Associate Labs

Hands-on labs from my AWS Certified Developer – Associate preparation programme. Every lab is a business scenario for the same fictional client, **Onward Logistics**, a fast-growing last-mile delivery company in West Africa. Each lab is solved with infrastructure as code and defended in a live review.

## How the labs are deployed

Every lab stack is deployed by **CloudFormation Git sync** from this repository's `main` branch.

1. `bootstrap/github-connection.yaml` is deployed once and links the AWS account to this repository.
2. `bootstrap/git-sync.yaml` creates the Git sync role and one sync configuration for the lab being worked on, pointing at that lab's `deployment.yaml`. Switching labs is one redeploy with different `Lab` and `StackPurpose` parameters. The previous lab's stack stays in place, no longer synced, until it is deleted.
3. From then on, a merged change to the current lab's template or deployment file redeploys its stack. The sync configuration uses a `FILE_CHANGE` trigger, so changes to other labs never redeploy it.

The Git sync role has the AWS managed `PowerUserAccess` policy, which covers every service except IAM and Organizations, plus IAM limited to resources named `onward-<environment>-*`. It works for every lab without changes, as long as lab IAM resources follow the naming standard.

## Conventions

These follow the Onward Logistics company standards:

- **Naming:** `onward-<environment>-<purpose>`, for example `onward-dev-iam-onboarding`. Environments are `dev`, `test` and `prod`.
- **Tags:** every taggable resource carries `Project=onward`, `Owner` and `Environment`. These are set once as stack tags in `deployment.yaml`.
- **Region:** `eu-west-1` (Ireland), unless a lab says otherwise. Git sync is not available in Africa (Cape Town).
- **No secrets in Git.** Passwords are generated by Secrets Manager at deploy time. Personal values such as alert email addresses live in SSM Parameter Store.
- **Cost:** every lab has a cleanup section. Resources are deleted once the lab is graded.
